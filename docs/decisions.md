# 設計判断ログ

「なぜその設計にしたか」を記録する。新しい判断が固まったら、日付・決めたこと・理由の順で
追記していく。

---

## バックエンドはGoogle Sheets + Apps Script

病院のスケジュール管理を、専用データベースを持つアプリではなく、Google Sheets +
Apps Script（Code.gs）で構築した。**病院のGoogle Workspaceアカウント側**で作成して
おり、個人アカウント側ではない点に注意（後から探すときに迷いやすいため明記）。

## パスコードロック(2211)とソフトデリート

誤操作防止のため入力にパスコードを設ける。削除は物理削除ではなくソフトデリート
（取り消し可能な状態）にしている。

## カテゴリとスタッフ選択、複数週リピート登録

オペ/検査/休み/研修/診療日/その他のカテゴリ、スタッフ選択、複数週にまたがる
繰り返し登録、絵文字マーキング(🍎/🍋)に対応。

## オペ検査ストップの印(2026-10-29)

「これ以上オペ・検査を入れたくない日」を示すため、診療日ステータスに「オペ検査ストップ」を追加。
その日は日付の横に🈵、セルを赤枠で囲み、オペ・検査を追加しようとすると入力画面に注意書きを出す
(登録自体は止めない。院内では例外もあり得るため)。データには文字だけを保存し、絵文字は表示時に
付ける(`STOP_MARK`を変えれば絵文字を差し替えられる)。バックエンドの変更は不要。
