# 不具合・課題ログ

## 解決済み

- **日付の正規化崩れ**: Google Sheetsは CSV の日付・時刻文字列を内部シリアル値へ
  自動変換してしまう。書き込み・読み込み両側で `setNumberFormat('@STRING@')` と
  `normalizeCellValue_()` を通すことで回避している。**この処理を外すと同じ不具合が
  再発するので注意**
- **二重送信バグ**: 修正済み（詳細な再発防止条件は次に触ったときに追記）
- **`loadEvents`のネットワーク不安定時の失敗**: リトライロジックを実装して対応
  （2026-08-28）

## 技術的な落とし穴（再発防止のためのメモ）

- Apps Script側のCORS対応には `Content-Type: text/plain` が必要
- POSTリクエストはサーバー側で処理をコミットしてから302リダイレクトを返す挙動になる。
  この順序を前提にした設計にしている
